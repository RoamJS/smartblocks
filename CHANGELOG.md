# Changelog

## 1.15.0

- The `jj` menu now has a shortcut footer styled after Roam Advanced Search. Use Ctrl+Shift+Enter or the Pin button to pin or unpin the selected SmartBlock. Pins stay in place after reloading Roam.
- Press Right Arrow to preview the selected SmartBlock without running it. Press Left Arrow to close the preview. The workflow list stays the same size in both states.
- Press Shift+Enter to open a custom SmartBlock's source in the right sidebar. Press Enter to run it.
- Search ignores spaces around the query and ranks direct workflow name matches ahead of fuzzy matches.
- Unnamed SmartBlocks stay out of the trigger menu until they have a name.
